# 기능목록

---

#### + : 구현 중 필요에 의해 추가된 기능
#### - : 처음부터 있었던 기능

---


#### - 구입금액을 입력해 달라고 UI를 보여주는 기능

#### - 로또 구입 금액을 입력받는 기능

#### - 로또 구입 금액을 검증하는 기능
    + 예외: 사용자가 너무 큰 값을 입력한 경우
    예외: 사용자가 1000원으로 나누어 떨어지지 않는 수나 문자를 입력한 경우 
    -> 다시 로또 구입 금액을 입력받도록

#### + loop: 사용자가 제대로 된 비용 입력을 할 때까지 반복하는 기능

---

#### - 로또 구입 금액을 기록하는 기능

#### - 로또 구입 금액을 로또 발매 횟수로 전환하는 기능

#### - 사용자가 몇개의 로또를 구매했는지 UI로 보여주는 기능

---

#### - 1개의 로또를 만들어서 기록하는 기능

#### - 만들어진 1개의 로또를 UI로 보여주는 기능

#### - loop: 로또 발행을 정해진 발매횟수만큼 반복하는 기능

---

#### - 당첨 번호를 입력하라고 UI를 보여주는 기능

#### - 당첨 번호를 입력받는 기능

#### + 당첨 번호 입력 문자열을 당첨 번호 리스트로 바꾸는 기능

#### + 당첨 번호 리스트의 크기가 6인지 검증하는 기능
    예외: 6이 아닐경우 -> 다시 당첨 번호를 입력하도록

#### - 당첨 번호들을 하나하나 검증하는 기능
    예외: 중복된 숫자, 1~45 이외의 숫자, 문자가 당첨번호로 입력된 경우 -> 다시 당첨 번호를 입력하도록

#### + loop: 사용자가 제대로 된 당첨 번호 입력을 할 때까지 반복하는 기능

---

#### - 보너스 번호를 입력받는 기능

#### - 보너스 번호를 검증하는 기능
    예외: 당첨번호와 중복된 숫자, 1~45 이외의 숫자, 문자가 보너스 번호로 입력된 경우 -> 다시 보너스번호를 입력하도록

#### + loop: 사용자가 제대로 된 보너스 번호 입력을 할 때까지 반복하는 기능

---

#### - 발행된 로또와 당첨 번호를 비교해서 몇개가 일치하는지 확인하는 기능

#### - 보너스 번호가 해당 로또에 있는지 확인하는 기능

#### - 계산된 결과를 당첨 통계에 추가하는 기능

#### - loop: 비교, 기록을 로또 발행 갯수만큼 반복해서 전체 통계를 만들어 내는 기능

---

#### - 출력할 내역에서 총 당첨금액을 계산하는 기능

#### - 로또 구입금액 대비 총 당첨금액 총 수익률을 계산하는 기능

#### - 당첨 통계를 UI로 보여주는 기능
