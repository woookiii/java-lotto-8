#### - 로또 구입 금액을 입력받는 기능

#### - 로또 구입 금액을 검증하는 기능

#### - 사용자가 몇개의 로또를 구매했는지 UI로 보여주는 기능
    문구: 8개를 구매했습니다.

---

#### - 1개의 로또를 만들어서 기록하는 기능
    - 1부터 45에서 중복되지 않는 숫자 6개를 뽑아서 오름차순으로 기록할 것

#### - 만들어진 1개의 로또를 UI로 보여주는 기능
    문구 샘플: [8, 21, 23, 41, 42, 43] 

#### - loop: 로또 발행을 정해진 발매횟수만큼 반복하는 기능

---

#### - 당첨 번호를 입력하라고 UI를 보여주는 기능
    문구: 당첨 번호를 입력해 주세요.

#### - 당첨 번호를 입력받는 기능

#### + 당첨 번호 입력 문자열을 당첨 번호 리스트로 바꾸는 기능

#### + 당첨 번호 리스트의 크기가 6인지 검증하는 기능
    예외: 6이 아닐경우 -> 다시 당첨 번호를 입력하도록
    에러문구:
    [ERROR] 당첨 번호는 6개여야 합니다.

#### - 당첨 번호들을 하나하나 검증하는 기능
    예외: 중복된 숫자, 1~45 이외의 숫자, 문자가 당첨번호로 입력된 경우 -> 다시 당첨 번호를 입력하도록
    에러 문구: 
    [ERROR] 숫자를 입력해야 합니다.
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    [ERROR] 중복되지 않은 숫자를 입력해야 합니다.

#### + loop: 사용자가 제대로 된 당첨 번호 입력을 할 때까지 반복하는 기능

---

#### - 보너스 번호를 입력받는 기능
    문구: 보너스 번호를 입력해 주세요.

#### - 보너스 번호를 검증하는 기능
    예외: 당첨번호와 중복된 숫자, 1~45 이외의 숫자, 문자가 보너스 번호로 입력된 경우 -> 다시 보너스번호를 입력하도록
    에러 문구: 
    [ERROR] 숫자를 입력해야 합니다.
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    [ERROR] 당첨번호와 중복되지 않은 숫자를 입력해야 합니다.

#### + loop: 사용자가 제대로 된 보너스 번호 입력을 할 때까지 반복하는 기능

---

#### - 발행된 로또와 당첨 번호를 비교해서 몇개가 일치하는지 계산하는 기능

#### - 보너스 번호가 해당 로또에 있는지 확인하는 기능

#### - 계산된 결과를 당첨 통계에 추가하는 기능
    출력해야 되는 유효한 결과일 경우 기록, 아니면 패스

#### - loop: 비교, 기록을 로또 발행 갯수만큼 반복하는 기능

#### - 출력할 내역에서 총 당첨금액을 계산하는 기능

#### - 로또 구입금액 대비 총 당첨금액 총 수익률을 계산하는 기능
enum 3 4 5 5+b 6 금액 쌍

#### - 당첨 통계를 UI 보여주는 기능
    문구 샘플: 
    당첨 통계
    ---
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    총 수익률은 62.5%입니다.
